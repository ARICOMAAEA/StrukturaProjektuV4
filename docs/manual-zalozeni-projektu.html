1 Otevřít wizard

Jeden self-contained HTML soubor. Žádná instalace, žádný build.

Otevři ho dvojklikem v prohlížeči. Běží přes file:// — odtud si sám odvodí, kde leží složka assets\ se šablonami.

3 Zkopírovat prompt

Poslední krok wizardu má dvě záložky.

  • Strom — náhled struktury, kterou projekt dostane. Jen ke kontrole.
  • Claude Code Prompt — to, co se kopíruje. Tlačítko Kopírovat.

Prompt je self-contained až na jednu věc: odkazuje se na složku assets\ v repu nástroje, odkud se kopírují skripty a šablony. Repo nástroje proto musí být dostupné.

Ve FÁZI 3 se tě Claude zeptá na GitHub username

Jsou to dvě různé identity a nesmí se slít:

Účet musí mít v cílové organizaci alespoň write přístup — jinak GitHub ten řádek v CODEOWNERS tiše ignoruje. Pokud username neznáš, nech zástupný symbol být a dořeš to později; Claude ho nemá hádat.

5 Ověřit hotový projekt

Akceptační brána musí projít, jinak projekt není hotový.

powershell -File "<PROJECT_ROOT>\scripts\Test-Topology.ps1" -ExpectedRemote "ARICOMAAEA/<REPO>"

Očekávaný výstup: GATE PROSEL — 9 kontrol OK.

Vždy s -ExpectedRemote Bez tohoto přepínače dá kontrola 8 výsledek SKIP a brána nahlásí GATE PROSEL, aniž by remote skutečně ověřila.

Ruční kontrola, že ochrana funguje — přímý push do main musí selhat:

GH006: Protected branch update failed
Co brána nekontroluje Test-Topology.ps1 ověřuje topologii (manifest, kořeny, junctiony, git, remote) — ne obsah knowledge souborů. Že vznikly všechny .md, si projdi očima proti záložce Strom.

6 Na co si dát pozor

Věci, které v tomto nástroji reálně kously.

Ruleset názvů větví nechrání

Ruleset personal-branch-naming se ve FÁZI 6 zakládá, ale na plánu team se nevynucuje. Pravidlo branch_name_pattern patří mezi metadata restrictions, které GitHub nabízí až na plánu Enterprise. Na nižším plánu API payload tiše přijme, ruleset vytvoří a hlásí jako aktivní — ale push větve mimo vzor projde.

  • Jediná skutečně vynucená ochrana je branch protection na main.
  • Konvenci <jmeno>/<co-dela> drží .github\CONTRIBUTING.md jako dohodu mezi lidmi.
  • Ruleset se zakládá dál — po přechodu organizace na Enterprise začne vynucovat sám.

Projektová vrstva má segment velkými, execution vrstva s velkým počátečním. Zrcadlí to reálné složky na disku — nesjednocovat.

UTF-8 BOM — jen kde je potřeba

BOM potřebují soubory, které PowerShell 5.1 čte zpátky bez explicitního -Encoding:

  • repos.json a REPOS.md — s BOM
  • STALE.md — bez BOM (check-drift.ps1 ho čte s explicitním -Encoding UTF8)
  • ostatní .md — nerozhoduje, čte je člověk a Claude

Plošné přidání BOM všem .md způsobí při prvním check-drift.ps1 -UpdateStale zbytečný diff.
